## Minimal workflow in each app repository

Create .github/workflows/build-android.yml in the app repository. Use the full commit SHA of this Common repository instead of the placeholder:

    name: Build Android APK

    on:
      workflow_dispatch:
        inputs:
          source_version:
            description: Upstream source version
            type: choice
            required: true
            default: stable
            options:
              - stable
              - main

    permissions:
      contents: write

    jobs:
      build:
        uses: a0534186049-byte/ArtCraft-Android-Common/.github/workflows/build-android-app.yml@<COMMON_COMMIT_SHA>
        with:
          app: photocraft
          source_version: ${{ inputs.source_version || 'stable' }}
        secrets:
          ARTCRAFT_SIGNING_KEYSTORE_BASE64: ${{ secrets.ARTCRAFT_SIGNING_KEYSTORE_BASE64 }}
          ARTCRAFT_SIGNING_PASSWORD: ${{ secrets.ARTCRAFT_SIGNING_PASSWORD }}
          ARTCRAFT_EXPECTED_CERT_SHA256: ${{ secrets.ARTCRAFT_EXPECTED_CERT_SHA256 }}

For GridCraft, set app to gridcraft. The central JSON profile is the source of truth for the product name, package ID, Release tag, and asset filename.

## Important boundaries

- Do not put the actual PhotoCraft or GridCraft upstream source into the Common repository.
- Do not copy the other app's logo, app icon, package ID, custom source edits, or signing key.
- Preserve the upstream source repository's LICENSE-APACHE, LICENSE-MIT, NOTICE, and asset-specific notices when distributing derived builds.
- App-specific Android modifications belong in that app's own repository unless they are genuinely reusable across multiple apps.
- WordCraft is not part of the current integration and must remain unchanged.
